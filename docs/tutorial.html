RiceFlux 使用教程 / Guide

下载纯文本 / TXT
  1. 选择数据 / Choose data

    打开“数据接口”，勾选 D1（6044）或 D2（RiceNavi 404），点击“应用数据集”。“来源 / 预览”仅查看来源，不改变分析。多个数据集同名材料保留为独立记录。可导入样本编号圈定群体。

    Choose datasets, inspect their provenance, then Apply. Identically named accessions remain separate; do not assume independent cohorts or identical seed identity.

  2. 查询基因 / Find a gene

    输入 MSU ID、RAP ID 或基因别名。共享别名需核对 ID；“ID 待核”没有被自动补名。矩形 D1/D2 表示数据覆盖，F 为已登记原文功能位点，H 为文献单倍型组分，L 为基因层文献。P 表示所选数据集有该基因已关联性状的实测值。在基因总览的“关联性状”切换该基因的不同性状。HC 未认证表示缺少逐调用质量证据。

    Search stable IDs or aliases. D1/D2 indicate dataset coverage; F functional-site evidence, H haplotype components, L gene-level literature. P marks observed values for a curated trait of that gene in the active datasets. Switch the current gene’s trait in the overview. Complete calls do not certify high confidence (HC). Filter on the dataset and evidence category.

  3. 选择位点 / Select sites

    “自选位点”可按坐标、CDS、启动子或文献预设选择。自选模式不受左侧 QC 再筛除。“预设出处”列出 DOI 与原文位置。FPLS1097622 对应 Zhang 等 2022 年 DTH7 的七位点关联单倍型，不是七个独立证实的因果变异。

    Manual sites override automatic MAF/missingness filters. Preset provenance supplies the DOI and paper locator. Missing calls remain missing; heterozygous unphased combinations are not resolved haplotypes.

  4. 读频率与表型 / Read frequencies and phenotypes

    按每个 ALT 分别显示频率。Missing 使用全部预期等位，MAF 取第二常见等位。二倍体每份预期两个等位，部分缺失中已知等位仍计数。组合频率按所有选点均完整的材料计数。来源稻区不是种植地；表型按地点、年份和指标分别展示。展开“组间检验”查看 Welch ANOVA 与 Kruskal–Wallis，展开“鉴定与地点溯源”查看规程。

    Allele frequency counts known alleles, including partial calls. Combination frequency uses complete accessions. Compare phenotypes within a matched trial endpoint. Open Tests for Welch and rank tests and Trial source for the protocol.

  5. 比较基因与材料 / Compare genes and accessions

    多基因页先选基因及各自定义，查看组合、成员、等位频率及连锁 r²。材料页可逐个或批量加入；每页六份便于读图，选择数量不限六份。雷达图为群体百分位，缺失不补零，无优劣方向或总分。

    Select genes and definitions before comparing combinations and LD. Add any number of available accessions; charts paginate six at a time. Radar percentiles are descriptive, not breeding merit scores.

  6. 保存与下载 / Save and export

    “我的工作区”保存筛选、布局、自选位点和材料。“下载基因数据”提供 TSV ZIP，含输入来源、所选位点、全部分型、表型、文献及名称复核。Excel 以制表符导入，材料编号设为文本。材料比较的导出包含全部已选材料。

    Save the workspace in your browser or export settings. Gene downloads are UTF-8 TSV bundles; import accession IDs as text in Excel. Material exports include every selected accession, not only the current chart page.

  7. 接入自己的数据 / Add your data

    准备 manifest.json 和五张表：samples、variants、genotypes、environments、phenotypes。也可按样本表单独导入基因型或表型。分型接受逗号分隔 ALT 和 1/2 等位编号。

    Import a complete package, or attach phenotype and genotype tables independently. Comma-separated ALTs and 1/2 calls are supported.
